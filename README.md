# FAILib — Perpustakaan Fakultas Agama Islam UMKLA

Portal Sistem Informasi Perpustakaan & Formulir Pengadaan Usulan Koleksi Buku Fakultas Agama Islam Universitas Muhammadiyah Klaten.

## Fitur Utama
1. **Formulir Pengadaan Usulan Koleksi Buku**:
   - Judul, Pengarang, Penerbit, Perkiraan Harga (auto-format Rupiah), dan Keterangan (Jumlah Buku Diminta).
   - Pengajuan multi-judul sekaligus dengan kalkulasi subtotal dan grand total otomatis.
   - Tabel transparansi status usulan pengadaan buku real-time.
2. **Panel Admin Perpustakaan**:
   - Dashboard rekapitulasi usulan koleksi buku, total eksemplar, dan total estimasi anggaran.
   - Manajemen usulan (tambah, edit, ubah status cepat, dan hapus).
   - Export Excel (`.xls`) rekapitulasi pengadaan koleksi buku.
   - Cetak Dokumen Resmi Formulir Pengadaan Buku (PDF/Print) lengkap dengan Kop FAI UMKLA dan tanda tangan Kepala Perpustakaan & Dekan FAI.
   - Pengaturan portal, buka/tutup form publik, dan keamanan ubah password admin.
